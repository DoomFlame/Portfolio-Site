HIGHLIGHTED PROJECT

Just Bite Back (2025)

Just Bite Back was a project that I worked as part of my high school senior year game production course during the second semester, although my team had been slightly planning our game during the first semester of the school year. The premise of the game was a PvP FPS game in which you first cook various foods in your customizable food truck, then use that food to fight other players, with different effects depending on the kind of food and the quality it was cooked at.

Due to the small team size (3 people) and the small amount of time we had in class, we were only able to prototype the outline of the FPS part of the game. I was the sole programmer for this prototype, in which I was able to implement a multiplayer system using Unity Lobby and Relay. If I had the opportunity to work on any project with no limitations and a full team, I would definitely want to flesh out this game more.

PROFESSIONAL PROJECTS

Undercover - Simcoach Games (2024)

This was a game based on picking the right clothing for spies so that they blend in to their mission environment. Our goal was to help those with learning disabilities determine what is appropriate attire for different scenarios.

I did most of the programming for this game, including the UI interaction, scene changes, sound manager, game manager and NPC dialogue.

Bankrupt - Simcoach Games (2024)

This was a game where we were tasked with recreated the arcade game "Burger Time", but with the goal of teaching the player something to do with money. Ultimately, we created a prototype that was intended to teach players how to add up different bill amounts to a final total.

It was a rewarding challenge to re-format a game in a way that teaches an important skill, especially with the game that we got which didn't give us much to work with. It was interesting to think about the impact games can have on education.

PERSONAL PROJECTS

In Case of Fire, Please Use Stairs - GCS (2026)

This game is currently in progress as part of my team from the Fall 2026 semester of the Game Creation Society at Carnegie Mellon. We have 7 active members. The main premise is playing as an elevator operator, having to manually control the direction of a number of elevators and maximize the number of NPCs that get to their correct destination in a timely manner.

So far, I have implemented a CCTV camera system using RenderTextures, ShaderGraph and a custom CCTVManager, as well as player pan/zoom control of each camera using a custom input script utilizing Unity's newer input system. Much more is to come, so check us out at the next GCS event!

Oneirophobia

This game was one of the very first games I ever made using GameSalad, and is nothing more than a walking simulator through pre-made pixel art assets I found online. It's amazing to see how far I've come!

My favorite thing about this project was the music I composed for the title screen of the game using FL Studio! Looking back on it, I would have layered the art more and had proper hitboxes to stop weird collisions between the player and the environment.
